# Android 0.2.0 验证记录

日期：2026-09-11。设备：Redmi Note 13 Pro+，Android 15。

- 覆盖安装旧版，versionCode 3 / versionName 0.2.0-preview，保留 Keystore 中的原配对。
- 电脑和手机连接同一 Wi-Fi，原 USB 测试地址通过 App 切换为无线地址。关闭全部 ADB reverse 后，App 显示「已同步 · 加密连接」和新的实时快照时间。
- 将开发用 Python 服务替换为最终打包 EXE，保留同一状态目录。短暂中断时 App 显示旧数据，服务恢复后手动刷新成功，无需重新配对。
- 最终 APK 覆盖安装后再次无线同步成功。悬浮服务处于前台；实际窗口横坐标在两次采样间变化，验证散步不是原地播放。
- 目视检查高清坐姿、伸展顶点与薄荷色界面。修复顶部额度标签遮挡叶片，最终悬浮伸展复查。
- Android 构建、7 项逻辑单元测试和 Lint 通过。桥接端 3 项测试通过；打包 EXE 独立完成启动、二维码生成、TLS 配对和授权查询检查。
- 资源共 520 张 440×420 PNG，来自桌面 v2.1.2 播放器导出；挥手和伸展各 16 帧，四种情绪及闭眼动作按需缓存。

未测试全部手机厂商的长期后台保活，也没有进行关闭电脑 VPN 的在线额度测试。局域网同步本身不需要访问 OpenAI；电脑获取新额度仍依赖其官方服务网络可达性。个人截图、地址、配对信息及真实额度均不包含在公开验证材料中。
