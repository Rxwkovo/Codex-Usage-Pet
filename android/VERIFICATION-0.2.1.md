# Android 0.2.1 验证记录

日期：2026-09-12

- 覆盖安装旧版，`versionCode 4` / `versionName 0.2.1-preview`，沿用同一调试签名并保留 Android Keystore 配对信息。
- `assembleDebug`、`testDebugUnitTest` 与 `lintDebug` 全部通过。
- 10 项领域测试覆盖无线地址限制、全部动画帧、伸展停留、缩团、额度边界、屏幕暂停和不同刷新率下的真实走动。
- 新增电脑与手机时钟偏差测试：数据新鲜度分别使用服务端时间与手机接收时间判断，恢复和更新时间换算到手机本地时间显示。
- 桌面内置同步端与独立同步端共 24 项 Python 测试通过，覆盖一次性配对、证书固定、令牌、字段白名单、慢连接截止、局域网来源与请求限频。
- 520 张 Android 素材均为 440×420，四种额度表情和闭眼状态保持独立。

本机完成的是编译、单元测试、Lint 和协议联调测试。本版新增的时钟偏差修复尚未在两台故意设置为不同时钟的真机上人工演示；旧版 0.2.0 已在 Redmi Note 13 Pro+ / Android 15 完成覆盖安装、USB 转 Wi-Fi、真实额度同步与悬浮窗走动验证。
