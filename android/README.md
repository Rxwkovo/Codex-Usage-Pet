# 码团 Android · 0.2.0 预览版

一个 APK，包含额度面板、设置和可以在其他应用上方活动的手绘码团。Android 8.0 及以上。

## 手机安装

安装 `CodexPet-Android-0.2.0-preview.apk`，可覆盖 0.1.1 保留配对。本版为调试签名的预览包，尚非应用商店发行版。

本版同步桌面 v2.1.2 的 440×420 高清动作：挥手/伸展各 16 帧，所有动作保持当前额度的四种表情并独立眨眼，睡下时使用闭眼表情；伸展顶点停留默认 18%，可调整到 0–40%。保留薄荷色按钮、按压缩放与水波反馈。
已在 Redmi Note 13 Pro+ / Android 15 验证覆盖安装、保留旧配对、从 USB 测试地址切换 Wi-Fi、关闭全部 USB 转发后的真实加密额度同步、悬浮服务与实际窗口走动。单台手机测试不代表所有厂商后台策略均兼容。

1. 打开码团，可以直接预览走动、坐下、休息、伸展、招手和缩团。
2. 点击「开启悬浮码团」，按系统提示授予悬浮窗、通知权限，再返回开启。
3. 悬浮宠物可拖动；单击招手，长按打开 App；通知中的「收起码团」停止服务。
4. 未连接电脑时不显示虚构额度。「演示表情」只切换表情，页面和悬浮窗均标注演示。

随机动作默认间隔 60–120 秒，首次预览约 15 秒；悬浮站立待机 20 秒后缩团。屏幕关闭时暂停绘制。
系统限制的页面可能不显示悬浮窗；厂商省电策略可能停止服务。没有开机自启和无障碍权限。

## 电脑同步

运行配套 `CodexPet-Sync-Bridge.exe`，从当前已连接的网卡中选择 Wi-Fi 地址。手机与电脑须在可互通的同一局域网，电脑可以同时保留网线。
默认端口 TCP 47831。同步程序不自动修改防火墙；如果手机无法连接，以管理员权限运行附带脚本（替换为同步端显示的电脑地址）：

```powershell
./allow-wireless.ps1 -Address 192.168.1.100
```

规则只允许选定网卡和本机地址、该 TCP 端口、直接连接的本地子网。适用于被 Windows 标为公共或专用的家庭 Wi-Fi，不修改路由器、VPN 或全局防火墙开关。请在信任的局域网使用。

电脑同步端显示一次性配对码，并将二维码保存到 `%LOCALAPPDATA%\CodexUsagePet\android-bridge\pairing.png`。
手机可粘贴配对码，或先把二维码原图传到手机，再点「导入配对二维码」。本版尚无实时相机扫码。
配对码 10 分钟有效、只可使用一次；再次配对请重新启动同步端。不要把配对码公开发布。

配对后每分钟尝试读取额度。桌面端使用已有只读 `read-usage.ps1`，不读取 Codex 登录文件。
只同步五小时、一周百分比及重置/更新时间。HTTPS 固定配对证书指纹；手机使用 Android Keystore 加密配对信息，关闭备份和设备迁移。
电脑只保存设备令牌哈希，证书私钥和缓存目录限制为当前 Windows 用户访问。

电脑关机、离开局域网或官方网络不可达时，显示上次数据与过期提示，中性表情不会伪装为最新额度。
手机不直接访问 OpenAI；手机与电脑的同步走局域网并绕过 HTTP 代理设置，但系统级 VPN 的路由仍可能影响连接。电脑仍必须具备访问官方服务的网络，不能承诺任何网络下都可获取新额度。
IP 变化或从 USB 转无线时，在 App「连接电脑 → 切换无线地址」输入电脑地址。使用原证书与设备令牌验证连接成功后才保存，失败保留原配对。更换同步端状态目录、证书或撤销设备后，需要重新配对。
如果页面显示「USB 测试连接」，该旧地址依赖 USB 转发，必须先切换到同步端显示的 Wi-Fi 地址。电脑同步端需持续运行；电脑休眠、程序退出或 Wi-Fi 断开会暂停更新。
退出同步端按 Ctrl+C；撤销全部已配对设备可运行 `CodexPet-Sync-Bridge.exe --host 电脑IP --reset`。

## 开发与验证

采用 Kotlin + 原生 Android View/Canvas，App 与悬浮窗复用图片播放器、行为逻辑和唯一额度仓库。
首版没有引入 Compose；现有 Windows 程序不依赖安卓模块。
520 张透明高清成品帧由 [Windows v2.1.2](https://github.com/Rxwkovo/Codex-Usage-Pet/tree/v2.1.2) 原播放器导出：8 张待机表情 + 64 个动作姿势 × 8 种情绪/睁闭眼组合。图像按需解码，每个视图最多缓存约 12 MiB，避免一次装入全部高清帧。
重新导出时，将 v2.1.2 源码放在独立目录，运行 `./export-frames.ps1 -WindowsSource 该目录`。Android 直接使用提交的成品帧，正常构建无需 Windows WPF。

Android Gradle Plugin 9.1.1，Gradle Wrapper 9.3.1，compile SDK 37，target SDK 35。
推荐 Android Studio 自带 JDK。Windows 中文路径请运行：

```powershell
./build-windows.ps1
```

脚本在当前用户临时英文目录中编译以避免测试类加载失败；产物复制到本目录 `dist`。
它运行 APK 打包、7 项领域逻辑单元测试与 Android Lint。首次构建需要下载依赖。

电脑服务源码见 `../bridge`。TLS、一次性配对、未授权访问与敏感字段过滤测试：

```powershell
python -m unittest discover -s ../bridge -v
```

详见交付目录的验证记录，区分代码测试、模拟器测试和真机测试。
