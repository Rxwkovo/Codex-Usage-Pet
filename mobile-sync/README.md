# 桌面设置中的手机连接

Windows v2.2.2 将同步服务嵌入主 EXE。入口是 **设置 → 手机连接**，托盘和宠物右键菜单也提供快捷入口。无需另装 Python，也无需另开命令行同步端。

1. 电脑与手机连接同一可互通的局域网，推荐同一 Wi-Fi。
2. 在设置中选择当前电脑地址，点击「保存并开启同步」。可调整端口（默认 47831）和一次性配对码有效期（默认 10 分钟，范围 1–60）。
3. 手机码团的连接页面粘贴配对码，或导入电脑保存的二维码原图。手机预览版暂不支持实时相机扫码。
4. 设置中显示已配对手机数、最近两分钟内发起同步的手机数及最后请求时间。手机通常每分钟更新一次，App 在后台被系统暂停时可能停止请求。
5. 「关闭同步」停止服务并关闭自动开启；退出码团也会停止服务。关闭设置窗口不会停止已开启的服务。「生成新配对码」不会撤销旧设备；「解除全部手机配对」会立即使全部设备令牌失效。

本页操作即时生效，其他设置页仍通过「保存并应用」保存。首次默认关闭同步；可选择随码团启动，不添加 Windows 开机自启。

## 网络与已有配对

只列出当前处于连接状态的局域网 IPv4，优先 Wi-Fi，排除常见虚拟网卡、VPN、环回及链路本地地址。仅监听选中的地址，不监听所有网卡。

如果连接不通，点击「允许局域网连接…」会请求 Windows 管理员授权。规则只允许所选网卡、所选本机地址、该 TCP 端口和当前同步程序，来源限制为直接连接的局域网；不修改路由器或 VPN。该规则可以在 Windows 防火墙中按名称「码团 · 手机局域网同步」删除。

现有独立同步端如果仍占用同一地址/端口，请先退出。v2.2.2 沿用默认 `%LOCALAPPDATA%\CodexUsagePet\android-bridge` 中的证书与设备哈希，所以默认目录已有配对无需重新导入；使用自定义测试目录的旧实例不会自动迁移，通常需在新设置页重新配对。Android 0.2.2 可验证原证书和令牌后切换无线地址，失败保留原连接，并用服务端时间校正电脑与手机的时钟偏差。

电脑关机、手机离开局域网或电脑在线额度不可用时，手机展示缓存及过期提示。手机不直接访问官方服务；电脑仍需能获取在线额度。局域网连接不会绕过操作系统的 VPN 路由规则。

## 协议与进程

兼容 Android 分支的 `mdt1:` URL-safe Base64 JSON 格式：`url`、SHA-256 证书指纹 `pin`、一次性 `code`。TLS 1.2 及以上，`POST /pair` 用邀请交换随机令牌，`GET /usage` 用令牌读取数据。没有网络管理接口和远程命令执行接口。

`protocol.py` 复用 Android 分支的证书、配对和额度白名单实现；`desktop.py` 添加桌面进程生命周期、局部控制和状态。设备只保存令牌哈希；邀请和二维码放在当前用户私有目录，使用、过期或退出时清除。TLS 握手在线程中进行，限制总并发、每来源并发、请求大小和绝对连接时限，避免单个设备占满服务。

服务直接读取当前桌面版本的 `usage.json`，只转发五小时、一周剩余百分比、重置时间、更新时间、服务端时间和数据状态，不再单独请求官方额度。服务端时间只用于校正电脑与手机的时钟偏差；手机协议将超过两分钟或超过重置时间的数据视为过期，保留保守的缓存标识。

`%LOCALAPPDATA%\CodexUsagePet\mobile-link` 保存连接设置和临时状态；控制命令带当前会话标识，仅从私有本地文件读取。组件跟随桌面父进程退出。分发使用 PyInstaller 目录包嵌入主 EXE，无额外控制台窗口。

## 构建与检查

使用 Windows x64、Python 3.12/3.13：

```powershell
python -m pip install -r mobile-sync/requirements.txt
python -m unittest discover -s mobile-sync -v
powershell -NoProfile -ExecutionPolicy Bypass -File tests/mobile.tests.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

生命周期测试使用隔离目录和临时环回端口，不接触实际手机配对；检查配对、续期、撤销、旧令牌持久化、额度白名单、TLS 慢连接、二维码清理及父进程退出。可以设置 `MOBILE_TEST_EXE` 为构建后的组件路径，再运行同一测试验证分发包。
